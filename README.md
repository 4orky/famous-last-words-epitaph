The funniest possible famous last words, as a single tombstone epitaph. The program writes one line to `/output/entry.txt`:

> I see the light. It's a train.

## Why this line

- **It is dying speech, carved in stone.** "I can see the light" is what the dying always say; the stone just records it, one short line, no stage directions, no explanation.
- **A real joke, not a mild pun.** The first sentence sets up the oldest deathbed cliché there is, and the second sentence takes it literally and runs it over.
- **The surprise lands in one word.** "Train" re-reads everything before it: the light was never heaven, it was headlights.
- **It stays in the head.** Eight words, two beats, quotable to a friend in one breath.
- **Original.** Written for this bounty from fifteen scored candidates; the full scoring table is in `CANDIDATES.md`.

## Run it

```sh
python3 main.py
```

The program validates its own output before writing: a single non-empty line of at most 150 characters, written UTF-8 with mode 0644.
